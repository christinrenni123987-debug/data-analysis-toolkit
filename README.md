A beginner-friendly toolkit for data exploration, cleaning, visualization, probability distributions, and statistical inference.

## Features

- Import CSV datasets
- Export cleaned dataset
- Missing-value analysis
- Duplicate check
- Data cleaning and preprocessing
- Descriptive statistics
- Summary tables
- Histogram and boxplot
- PDF and CDF plots
- Q-Q plot
- Goodness-of-fit using Kolmogorov-Smirnov test
- Normality testing using Shapiro-Wilk, Kolmogorov-Smirnov, and Anderson-Darling
- Confidence interval
- One-sample t-test
- Correlation heatmap

## How to Use

1. Open `Data_Analysis_Toolkit.ipynb` in Google Colab.
2. Upload your CSV dataset.
3. Run the cells from top to bottom.
4. Choose a numeric column for analysis.
5. Read the generated tables, plots, p-values, and conclusions.
6. Export the cleaned dataset.
